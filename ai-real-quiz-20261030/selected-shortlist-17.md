## 3. 영상 길이와 권리 관련 주의

- Sora/Veo/Seedance/Wikimedia 후보의 일부는 원본이 **8~8.5초**다. 10초를 위해 무리하게 늘리지 않고 8~11초로 편집할 것.
- **Pexels는 무료 시청/다운로드 가능 여부와 별개로, 단순 편집본의 독립적 재배포에는 제한이 있을 수 있다.** GitHub MP4 재업로드 전 재배포 권한 확인 필요.
- TikTok·Instagram·Tesla YouTube·Storyful·신문사 영상도 **공개된 영상이라는 이유만으로 GitHub 재배포 가능한 것은 아니다**.
- 이 파일은 **재생 링크 및 콘텐츠 선택 기록**이며, 영상 자체는 수록하지 않는다.
- REAL 판정은 원본 영상과 실제 촬영 근거가 일치하는지 최종 다운로드 전에 다시 확인.
- **실행 상태:** 링크 목록 정리 PASS / 영상 17개 직접 재생·다운로드·재편집 권한 검증 NOT_RUN / MP4 제작 NOT_RUN.
